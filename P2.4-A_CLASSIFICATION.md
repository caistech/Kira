   Formally confirm: **A Business Valuation is owned by the Organisation.**

   - `person_id` = provenance (who commissioned/updated)

4. **Dependencies for migration:**  
   - `organisation_memberships` resolver must reliably map person → organisation  
   - `getCurrentOrganisationContext()` must be available at all write boundaries  
   - Admin exec cohort query (`lib/admin/exec.ts`) must be migrated in same phase

5. **Do not migrate yet.** P2.4-B must produce a signed-off decision record before P2.4-C begins.
